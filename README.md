A [make.fun](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) entry for
**One Line of Earned Pride**: one line, 1 to 240 characters, a quiet earned
moment of pride for someone in a scene.

`main.py` deterministically writes exactly one original line to
`/output/entry.txt`:

> Eleven Sundays he'd spent rebuilding the engine in the driveway, and when
> it finally coughed awake, his daughter looked at him like he could fix
> anything.

Run it with:

```sh
python3 main.py
```
